Yes, completely. There is no paid tier, no per-seat pricing, no trial that expires and no in-app purchases. There is also no advertising anywhere in the app or on the website.

No. Written and open-ended answers are never auto-marked wrong — anything a grading rule cannot settle confidently is handed to you to read and score yourself. Nothing is lost. Answers are saved on the participant's device the moment they are given, so a dropped connection never costs progress. Everything syncs back up automatically once the device is online again.

Mostly, yes. Creating a quiz works offline, and so does answering one you have already joined — answers are saved on the device and sync when the network returns. Two things do need a connection: signing in, and joining a quiz by code or QR, because the code has to be looked up. The practical advice is to get everyone joined while the network is working; after that it can drop without costing anything.

There is nothing to pay. Participants join with a 6-character room code or a QR code, then sign in with their existing Google account — there is no Quizoma password to create and no separate signup form.

Any of them. Taking a quiz runs in a normal web browser, so an iPhone, iPad, Android phone, Chromebook, Windows laptop or Mac all work. Participants go to quizoma.com/take and enter the room code — there is nothing to install.

Each question carries a matching rule that you choose: exact match, case-sensitive exact, smart typo-tolerant match, keyword coverage, or numeric equivalence. A question can use several rules at once and is accepted if any of them is satisfied. Anything left unsettled goes to you for review.

Yes, with the numeric equivalence rule. Numbers are compared as numbers rather than as text, so 7, seven and 7.0 all count as the same answer, as do written forms like "one thousand five hundred" and 1500.

Yes, and they are worth knowing before you start building. By default an account can own 10 quizzes, each quiz can hold 20 questions, and an account can be joined to 50 quizzes.
